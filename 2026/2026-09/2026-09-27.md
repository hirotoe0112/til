## JavaScript

クロージャ

変数を外部から隠ぺいして関数からのみアクセス可能にする。グローバル環境の汚染を防ぐ。

以下の例で`allTransactions`などの変数は`addIncome`などの関数からのみアクセスできる。

また作成したインスタンスごとに変数の状態を保存できる。

```javascript
function financialTracker() {
  const allTransactions = [];
  const incomeTransactions = [];
  const expenseTransactions = [];

  return {
    addIncome: function (date, source, amount) {
      const data = {
        type: "income",
        date,
        source,
        amount,
      };
      incomeTransactions.push(data);
      allTransactions.push(data);
    },
    addExpense: function (date, item, amount) {
      const data = {
        type: "expense",
        date,
        item,
        amount,
      };
      expenseTransactions.push(data);
      allTransactions.push(data);
    },
    generateReport: function () {
      console.log(allTransactions);
    },
  };
}

const tracker = financialTracker();
tracker.addIncome("2026-09-26", "Salary", 100);
tracker.addExpense("2026-09-27", "Groceries", 4.5);
tracker.generateReport();
```

プロトタイプ

JavaScriptで継承を実現する。

オブジェクトはプロトタイプというものを持っており、そのオブジェクトにない関数が呼び出されるとプロトタイプの関数を探しにいってそれを実行する。

それを最上位でプロトタイプを持たないオブジェクトに辿り着くまで実行するのがプロトタイプチェーン。

インスタンスごとに関数を定義すると各関数がそれぞれメモリに格納され、メモリ効率やパフォーマンスが良くない。

プロトタイプを使うことで、インスタンス全体で関数を共有できるためメモリの節約になる。
