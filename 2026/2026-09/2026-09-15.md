## WordPress

セキュリティ対策

- 管理画面⇒設定⇒ディスカッション⇒「アバターの表示」のチェックを外す⇒変更を保存
- Edit Author Slugをインストールし、ユーザ⇒プロフィール⇒投稿者スラッグを変更
- Code Snippetsをインストールし、以下をスニペットに追加

```php
// 1. 未ログイン状態では REST API のユーザー情報を返さない
  add_filter( 'rest_endpoints', function ( $endpoints ) {
        if ( ! is_user_logged_in() ) {
                unset( $endpoints['/wp/v2/users'] );
                unset( $endpoints['/wp/v2/users/(?P<id>[\d]+)'] );
        }
        return $endpoints;
  } );

  // 2. /?author=1 → /author/xxx/ のリダイレクトを止める
  add_action( 'template_redirect', function () {
        if ( is_admin() ) {
                return;
        }
        if ( isset( $_GET['author'] ) || is_author() ) {
                wp_safe_redirect( home_url( '/' ), 301 );
                exit;
        }
  } );

  // 3. 著者アーカイブへのリンクを出力しない
  add_filter( 'author_link', function () {
        return home_url( '/' );
  }, 10, 1 );

  // 4. oEmbed レスポンスから著者情報を除去
  add_filter( 'oembed_response_data', function ( $data ) {
        unset( $data['author_name'], $data['author_url'] );
        return $data;
  } );

  // 5. xmlrpc.php を無効化
  add_filter( 'xmlrpc_enabled', '__return_false' );
  add_filter( 'wp_headers', function ( $headers ) {
        unset( $headers['X-Pingback'] );
        return $headers;
  } );
  remove_action( 'wp_head', 'rsd_link' );

  // 6. WordPress のバージョン表記を出さない
  remove_action( 'wp_head', 'wp_generator' );

  // 7. xmlrpc.php へのアクセス自体を遮断
  add_action( 'plugins_loaded', function () {
        if ( defined( 'XMLRPC_REQUEST' ) && XMLRPC_REQUEST ) {
                http_response_code( 403 );
                exit;
        }
  } );
```
