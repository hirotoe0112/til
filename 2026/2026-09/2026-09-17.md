## PostgreSQL

`pg_trgm`で類似データを検索できる。

trgmはトライグラムで、文字列を3文字ごとに区切って比較する手法。

検証用テーブル作成

```sql
CREATE TABLE recipes (
    id SERIAL NOT NULL,
    instruction VARCHAR(255) NOT NULL,
    created_at TIMESTAMP,
    updated_at TIMESTAMP,
    PRIMARY KEY (id)
);
```

データを投入する

```sql
INSERT INTO recipes (instruction) VALUES
('醤油を大さじ2杯加えます。'),
('醤油を大さじ２杯加えます。'),
('しょうゆを大さじ2杯加えます。'),
('醤油を大匙2杯加えます。'),
('醤油を大匙２杯加えます。'),
('醤油は大さじ2です。'),
('醤油を大さじ2杯入れます。'),
('醤油を大さじ2杯入れる。'),
('醤油を大さじ2杯投入します。'),
('しょうゆを大さじ2杯加え、炒めます。'),
('砂糖を大さじ2杯加えます。'),
('砂糖を大さじ1、醤油を大さじ2杯加えます。'),
('ごま油を大さじ2杯加え、ボウルであえます。'),
('醤油を入れたら、ひと煮立ちするまで待ちます。'),
('3分間、600wで加熱します。'),
('600wで3分間加熱します。'),
('レンジで3分間あたためます。'),
('豚薄切り肉100g、ピーマン2個、なす2本'),
('豚肉100g　ピーマン2個　なす2本'),
('肉の色が変わるまで炒めます。'),
('焼き色がついたら裏返します。')
;
```

拡張機能を有効にする

```sql
-- 初回のみ
CREATE EXTENSION IF NOT EXISTS pg_trgm;
```

類似度を検索する

```sql
-- パラメータ変数と既存データの類似度を計算
SELECT
    id,
    instruction,
    word_similarity('醤油を大さじ2杯加えます。', instruction) AS score
FROM recipes
ORDER BY score DESC;
```
