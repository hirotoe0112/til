## Python（Django）

テストに必要なモジュール

- `rest_framework.test`
  - `APIRequestFactory`：テストコード内でAPIを実行する
  - `force_authenticate`：テストコード内で認証を通す
- `unittest.mock`
  - `patch`：メソッドをモックする
  - `MagicMock`：あらゆるオブジェクトのモックを作成する
- `django.test`
  - `TestCase`：DBに接続するテスト
  - `SimpleTestCase`：DBに接続しないテスト

テストの書き方

```python
from django.test import TestCase
from rest_framework.test import APIRequestFactory, force_authenticate
from rest_framework import status
from unittest.mock import patch, MagicMock

class SampleClassTestCase(TestCase):

  def test_get_returns_success(self):
    from sample_module.sample_file import SampleClass
    request = APIRequestFactory().get('/api/sample/hoge/')
    force_authenticate(request, user=MagicMock(username="testuser", pk=1))
    response = SampleClass.as_view()(request)

    self.assertEqual(response.status_code, 200)
    self.assertEqual(response.data, {
      "status": "success"
    })

  def test_post_inserts_rows(self):
    from sample_module.sample_file import SampleClass
    payload = {
      "hoge": "fuga",
    }
    request = APIRequestFactory().post('/api/sample/hoge/', payload, format='json')
    force_authenticate(request, user=MagicMock(username="testuser", pk=1))
    response = SampleClass.as_view()(request)

    self.assertEqual(response.status_code, 200)
```

`setUpTestData`メソッドを書くとテストクラス全体で実行前に一度だけテストデータを投入してくれる。
