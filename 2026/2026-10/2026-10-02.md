## ナレッジグラフ

概要

- 情報をノードと関係性で表し、グラフ構造で表現する
- 検索エンジンやWikipediaなどはナレッジグラフの活用例
- 情報にコンテキストを与えることができる、データをコンテキストで理解できる

プロパティグラフモデル

- ノードはドメイン内のエンティティを表し、関係はエンティティ間の関係を表す
- ノードはkey-valueのプロパティを持つ
- ノードはグラフ内での目的を示すラベル（人、商品、など）を持つ
- 関係は関係の種類（好き、出演した、など）と方向性を持つ
- 関係はkey-valueのプロパティを持つ

どうやって実装する？

- `Neo4j`が有名なライブラリ
- AmazonのNeptuneでもグラフデータベースが構築できる

検索方法

- Cypherという記法を使用する。

こういう感じで情報を取得できるらしい。取得したい関係性を記述してそれに合致したものを返す感じか。

```
// 山田翔太が出演したことのある映画を返す
MATCH (a:Actor {name: '山田翔太'})-[:ACTED_IN]->(m:Movie)
RETURN m.title, m.genre

// 山田翔太と共演したことがある俳優
MATCH (a:Actor {name: '山田翔太'})-[:ACTED_IN]->(:Movie)<-[:ACTED_IN]-(co:Actor)
RETURN DISTINCT co.name
```
