## AST（抽象構文木）

プログラムの本質的な構造を木構造で表現したもの。

```ts
const a = 1 + 2;
```

と

```
const a    = 1+2
```

は見た目は違うが本質的な構造は同じ。

prettierでは

```bash
prettier --debug-check .
```

を**整形前**のコードに対して実行することで整形によりASTに変更がないことを確認できる。

## Stacked PR

[GitHub Stacked PR は branch を積むだけの運用と何が違うのか](https://zenn.dev/yamk/articles/github-stacked-pr-vs-manual)

Stacked PRとは、手動でmain→branch1、branch1→branch2、branch2→branch3というように派生させていくのをネイティブでサポートしたもの。

手動だと、このブランチは最終的にはmainに向いているということがGitHubには理解できないが、Stacked PRを使えば最終的にmainに向いていることが理解できる。

これにより、ブランチ保護のルールなどもmainにマージするときのルールが適用されるなど便利になる。
